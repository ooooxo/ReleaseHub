# Release Hub

自部署的发版 / 资源分发服务：管理应用的多版本发布、资源库的多文件分发，以及对外的临时分享。本文件是**术语表**，统一前端与后端对同一概念的称呼，不记实现细节（实现取舍见 `docs/adr/`）。

## Language

**库（Library）**：
顶层容器的统称，分两类——「应用」与「资源库」。在「总览」页以卡片形式并列。
_Avoid_: 仓库、项目、repo（代码里 `repoType` 仅指应用的子类型，勿外延为「库的类型」）

**应用（App）**：
有版本线的库：同一应用按 SemVer 累积多个「版本」。子类型由 `repoType` 区分：`tauri`（须三段式 SemVer、含各平台包及 `.sig` 签名）与 `general`（通用，版本号宽松）。
_Avoid_: 软件、程序（口语可用「软件」，但术语统一用「应用」）

**资源库（Resource）**：
无版本线的库：容纳多个相互独立的「文件」，可含子目录、可打包 ZIP。
_Avoid_: 文件库、素材库

**版本（Version）**：
应用下的一次发布，绑定一个版本号与若干平台包。属于「应用」专有概念，资源库没有版本。
_Avoid_: release、发版（动词可用「发版」，名词用「版本」）

**文件 / 资源项（Item）**：
资源库内的一个条目，带显示名、可选版本号标签、可选简介、大小。是资源库内的**从属条目**，不是独立的「库」。
_Avoid_: 资源、附件

**临时文件（Temp）**：
单份、可定时到期自动删除的对外分享，独立于任何库。可为单文件或文件夹。
_Avoid_: 临时传输、临时分享（统一「临时文件」）

**总览（Home）**：
首页，并列展示所有库与临时文件。
_Avoid_: 首页、主页、Dashboard

## 个体性的边界（grill 厘清）

「个体性」按层级区分，勿混淆：

- **库层级**（应用 / 资源库）：每个库是有身份的独立实体，UI 上须保留图形化个体性（总览的 bento 卡、详情入口）。
- **条目层级**（版本 / 文件）：是某个库下的从属条目，个体性服从于所属库；UI 上以紧凑图形卡呈现身份，编辑/操作收进「展开态」详情层。
