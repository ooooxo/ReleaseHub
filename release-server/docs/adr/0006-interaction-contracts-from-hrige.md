# 交互契约向 Hrige 看齐：无模态、详情带、一次交、上传托盘、纯 CSS 动效梯子

用户要求「参考 Hrige 优化整体设计，主要修交互 bug，加动效」。审计出 30 处交互 bug，其中一批不是个别失误，而是同一个结构病：AppDetail 有 8 颗分散的「保存」+ 一处失焦自动存，高级区每次保存都重载并覆盖别处未存的编辑，卡片标题直接渲染未存值，模态取消后脏值漏进发布；展开卡 `grid-column: 1 / -1` 瞬移到新行；上传绑在页面上，传完把人拽回详情页。修个例会反复回来，所以按 Hrige（Coffice）已验证的契约整体重排交互，但**外观不动**（暗色 + 天蓝，ADR-0002 仍成立）。

## 决定

- **没有模态框**（源自 Hrige 0064 / 0065）。新建应用 / 资源库 / 版本改为从触发按钮长出的**浮层**；「对外接口」并入基本信息区就地显示（与资源库页一致）；「编辑发布说明」删除，改说明 = 展开该版本卡。原生 `confirm` / `title` / `<select>` 一并换成自绘件。
- **确认分两档**。条目级删除 / 取消用**两步确认**（按钮按一下进待确认态，片刻回落）；库级或不可逆（删库、完全重建、缺 `.sig` 仍发布、手改 platforms / files JSON）用**确认层**写清后果。
- **展开态以详情带呈现**（修订 ADR-0003 的「就地展开」几何）。卡留原位，编辑面从该卡所在行下方长出并指回卡；同一页同时只开一张。
- **一张卡一次交**（源自 Hrige 0067）。展开态的改动累积为**未存改动**，只在有改动时浮出「放弃 · 保存」；有未存改动时该卡不被自动收起、离页被拦。未存改动叠在新数据之上，列表重载不得覆盖它（审计 #10 的根）。改的是**更新清单**时按钮写明「保存并更新线上」；有未存改动时「发布」变为「保存并发布」，不静默代存。
- **上传托盘**。上传属于整个管理端：换页不中断，传完只发带链接的通知、不跳页；关标签页前拦一下。投放区点击选文件（可多选），文件夹走区内单独的文字钮。
- **动效：纯 CSS 梯子，不引 GSAP**。照搬 Hrige `tokens.css` 的时长（press / fast / med / slow / sheet）、曲线、位移 token 与 reduced-motion 归零段；Vue `<Transition>` + CSS 承载，少数数字滚动手写 rAF。性格「克制 + 结果时刻有情绪」：日常只用 ease-out，上传完成 / 复制成功 / 发布成功才用 spring-soft 与描线。

## Considered Options

- **整体换成 Hrige 外观 / 加亮色主题**：工作量翻倍且推翻 ADR-0002；交互病不在配色 → 否。
- **引 GSAP + 搬 `motion.ts`**：Hrige 用它服务 3D 平面图与图层编排，ReleaseHub 没有这类需求；破「前端仅 vue / pinia / router」→ 否。
- **展开卡保持通栏 + FLIP 重排**：不瞬移了，但被点的卡仍换位置 → 次优。
- **失焦即存**：快，但没法整批撤回，半成品 JSON / 说明会直接写进更新清单 → 否。
- **上传绑定在页上 + 离页拦截**：实现小，但传大文件时人被困在页上 → 否。

## Consequences

- 明确没搬的：Hrige 的外观（白纸 + 发丝、亮色）、GSAP、导航体系。日后再有人提「照 Hrige 做」，先看这一条。
- ADR-0003 的「折叠 / 展开两态」契约不变，只改展开的几何；临时文件的 Home 单格闭环（0003 已定、未实现）随托盘一起落地。
