# 视觉与 ooooxo.com 入口页统一，液体封面用入口页同一个库

ReleaseHub 是 ooooxo.com 入口页下的一个服务：从入口页点进来，管理端和对外分享页原先像另一家产品（分享页还是初版琥珀，管理端是天蓝主按钮 + 网格底纹）。用户决定：整个 ReleaseHub 的样式参考入口页，用同样的库。

决定：
- **取值以入口页 / 入口管理页为准**：表面 `#141416 / #1c1c1f / #222226`，描线 .08 / .15，圆角 12 / 9；主按钮为墨色胶囊（白底黑字），次按钮为浅底内描线胶囊；输入框浅底内描线、聚焦天蓝描线加外环；胶囊 12px 常规字重，不再全大写加字距。去掉网格底纹。
- **品牌位**：左上角 `ooooxo` 字标，后跟服务名；管理端侧栏、登录页、分享页同一枚。
- **液体封面**：直接用入口页的 `liquid.js`（同域根路径 `/liquid.js`，nginx 把 `/` 交给入口页），不复制一份——复制件会和入口页走样。同名的库在入口页、总览卡、详情页头、分享页出同一族液体（种子取名称、色调取类型、液面压进名字）。没加载到它或 WebGL 不可用时只报错不出图，页面照常可用（与入口页自己的约定一致）。
- **分享页**：九个对外页面共用一份样式与外壳（`lib/download-pages.js` 的 `shell()`）；单文件页沿用入口页的单幅构图（左文右液），列表页液体在标题区背后。
- **一屏一个主操作**：同屏重复出现的操作（文件行的下载等）一律次按钮。

## Consequences

- ReleaseHub 依赖入口页在同域提供 `/liquid.js`；脱离 ooooxo.com 单独部署时液体不出图（页面可用），本地开发要么起入口页，要么临时把 `liquid.js` 放进 `public/`（构建会清空该目录，勿提交）。
- 部分取代 ADR-0002（网格、天蓝主按钮）；ADR-0001 系统字体栈不变，分享页也不再连 Google Fonts。
