# 配色采用 morii 中性表面 + 科技强调色对（弃全琥珀）

初版设计「到处琥珀」的战术风与 morii 理念冲突；曾折中为「暗色 + 琥珀唯一强调」，但出预览后确认琥珀整体观感差。改为直接采用 morii-card 的配色体系。

决定：
- **表面中性**（暗色 card `#1a1a1c` / bg `#0c0c0e` / inset `#25252a`），绝不染色。
- **强调用 morii「科技」领域色对**：天蓝 `#38bdf8`（主，呼应产品 favicon 既有蓝）+ 靛蓝/紫 `#6366f1`（点缀）。
- 染色面积 ≤10%（60-30-10）；强调靠字重，彩色只落在 chip 与关键数值，不染整段文本/标题。
- 类型胶囊（Tauri / 通用 / 资源库 / 临时）用不同 text-grade hue 的 tint chip 区分，仍属克制范围。

## Consequences

- 推翻初版「琥珀唯一强调」方向；`global.css` 的强调 token 由琥珀改天蓝系，预览确认后回写。
- 网格背景、表面去染等克制纪律不变，只换强调色相与中性表面取值。
