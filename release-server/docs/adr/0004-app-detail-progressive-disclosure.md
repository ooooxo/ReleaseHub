# 应用详情页改用渐进披露，高级/危险/说明默认收起

原应用详情页（尤其 Tauri）整页平铺、零分层：手编 12 行 platforms JSON、「从磁盘完全重建」这类高级/危险操作，与「新建版本 / 上传 / 设为最新」日常操作同屏同权重；叠加 3~4 处大 textarea 与大量常驻说明段——这是「太复杂」的根因。

决定：按渐进披露重组信息架构。
- **主面**只留日常动线：顶部（应用名 + 发布态 + 新建版本）+ 版本卡网格（折叠两态，见 ADR-0003）。
- **收进「高级」展开区 / 抽屉**：platforms/files JSON 手编、pub_date、「从磁盘完全重建」、软件信息编辑、对外接口全部链接。
- **所有说明文字**收进 ⓘ tooltip / overlay，不再常驻。

## Consequences

- 高级能力不删除、只收起，老用户仍可达；日常用户默认看到清爽主面。
- 危险操作（完全重建 / 删除）移出主面，降低误触。
- 通用（general）应用详情页共用同一信息架构，仅 JSON 字段语义不同。
